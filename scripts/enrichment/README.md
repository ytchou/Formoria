# scripts/enrichment/

Enrichment-domain scripts grouped by concern.

| Directory | Purpose |
|---|---|
| `run/` | Core curation pipeline — curate, refresh, rerun, render, snapshot |
| `eval/` | Evaluation — brand census, trace export, cohort selection, search retrieval eval |
| `products/` | Curated product management — populate, validate, check links, mirror images |
| `images/` | Image pipeline — recovery audit, storage maintenance, hero resort, backfill |
| `ops/` | Operator actions — approve, reject, derive category, seed history |
| `data/` | Data seeding and import — Langfuse, embeddings, stockist import, founding facts |
